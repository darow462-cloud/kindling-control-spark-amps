    Your model cache and songs remain inside the local RoFormer workspace. Completed tracks are imported automatically after separation started with the controls above. Use Advanced Studio or manual WAV import if browser storage is unavailable. Spark amp presets are unaffected.
    
      
    
      
    
      
    Separate a song locally into drums, bass, vocals, guitar, piano and other instruments using HTDemucs 6-stem. Each result is saved as an individual WAV file that you can listen to or open in a DAW. No audio is sent to a cloud service.
    
      
    
        
    Before the first run: Standard downloads about 84 MB of HTDemucs weights; High Quality also downloads approximately 333 MB of fine-tuned weights. Models are cached locally. Internet is needed only to fetch missing weights. A Vulkan-capable GPU is recommended.
    
        
    Limitations: guitar separation is approximate. In dense metal mixes, overlapping guitars, cymbals, vocals and distorted bass may bleed into other tracks. The six outputs are instrument categories, not guaranteed individual musicians or overdubs.
    
      
    

      
    Native stem separation is currently provided only in the dedicated Windows Portable build. This browser/mobile build can still import an already separated WAV file into Analyze.
    
      
    
        
    
          
          
          
    Uses the existing 6-stem model for every track.
    
          
          
    This prevents digital overload but does not remove artifacts already produced by the model. It never compresses or independently normalizes individual track segments.

    Compare guitar tone Experimental
    
        
    Import a reference and your guitar recording, or record through a microphone/audio interface. Analyze matching eight-second sections and compare the frequency balance. Processing stays on this computer; no files are uploaded.
    
        
    Prefer an isolated guitar stem or riff. Comparing a full song with a solo guitar also measures drums, bass and mastering, so it cannot identify the exact amp settings.

            Send Console log
            
      
            This is exactly what will be sent: the newest  lines of the Console, with names in quotes, IDs and the amp's name and serial number removed from the text. The raw bytes are kept as they are; they can contain preset names and the amp's serial number.
            
      
            
      
      
      
            The log goes to the project's error-report service, and a public GitHub issue is opened that links to it. The issue shows only the app, version and number of lines, not the log or your note.
